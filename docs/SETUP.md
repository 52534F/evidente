# Development Setup

This guide explains how to set up the development environment after cloning the repo from GitHub.

## Prerequisites

- Node.js (v18+ recommended)
- npm (comes with Node.js)

## Setup Steps

### 1. Clone the Repository

```bash
git clone https://github.com/your-org/evidente.git
cd evidente
```

### 2. Install Dependencies

Since `node_modules/`, `package-lock.json`, `playwright.config.js`, `run-tests.js`, and `run-tests.sh` are in `.gitignore` (they're environment-specific), you need to install them:

```bash
npm install
```

This will:
- Create `node_modules/` directory
- Generate `package-lock.json`
- Install Playwright and serve packages

### 3. Install Playwright Browsers (for E2E tests)

```bash
npx playwright install chromium
```

### 4. Verify Setup

```bash
# Run unit tests (Node.js)
node tests/italian-unit.test.js

# Expected output:
# Running Italian module tests...
# ✓ A1 generates questions
# ✓ A2 generates questions
# ...
# All tests passed!
```

### 5. Start Development Server

```bash
npm run serve
# Opens at http://localhost:3000
```

Then open `http://localhost:3000` in your browser.

## Running Tests

### Unit Tests (Node.js)

```bash
node tests/italian-unit.test.js
```

Tests verify:
- Question generation for each level (A1-C2)
- Category structure validity
- Syntax blocks required fields
- Reply choices and correctIndex
- Async API (generateQuestion returns Promise)

### E2E Tests (Playwright)

```bash
# Headless
npm test

# With browser UI
npm run test:headed

# Debug mode
npm run test:debug
```

## Adding a New Language

1. Create directory: `languages/<iso-code>/`
2. Add JSON data files: `a1.json`, `a2.json`, etc.
3. Create `index.js` that loads JSON via `fetch()` and exports the language interface
4. Register in `app.js`:
   ```javascript
   const languages = {
     it: require('./languages/it/index.js'),
     es: require('./languages/es/index.js')  // Add your language
   };
   ```
5. Add script tag in `index.html`:
   ```html
   <script src="languages/es/index.js"></script>
   ```

## Key Files in .gitignore

These files are not committed to the repo because they're generated locally:

| File/Folder | Reason |
|-------------|--------|
| `node_modules/` | NPM dependencies (regenerated with `npm install`) |
| `package-lock.json` | Lock file (platform-specific) |
| `playwright.config.js` | Generated by Playwright install |
| `run-tests.js` | Generated by Playwright install |
| `run-tests.sh` | Generated by Playwright install |
| `test-results/` | Test artifacts (temporary) |
| `sources/` | Source maps and debug files |
| `*.docx`, `*.pptx`, `*.pdf` | Binary documents |

## Troubleshooting

### "Cannot find module" error
Run `npm install` to install dependencies.

### Tests fail with "Failed to load data"
Make sure you're serving the app via HTTP (not file:// protocol) so `fetch()` works in the browser. Use `npm run serve`.

### Playwright browser not found
Run `npx playwright install chromium` to download the browser binaries.
