## Quality & Didactic Guidelines

### Principle 1: Authentic Italian Expressions
Sentences must be utterances a native speaker would actually say.

✅ **Good**: "Maria legge un libro" (complete thought)  
❌ **Bad**: "io parlo" (incomplete, lacks context)

**Fix**: Add context:
```json
"sentence": [
  {"text": "io", "role": "Soggetto"},
  {"text": "parlo", "role": "Verbo", "question": "parlare (io)"},
  {"text": "italiano", "role": "Complemento"}
]
```

### Principle 2: Question Hint Sufficiency
The `question` field must provide **just enough** information.

| Word Type | Hint Strategy | Example |
|-----------|---------------|---------|
| Verbs | Infinitive + person | `"parlare (io)"` |
| Nouns | Full noun + gender | `"il libro (m)"` |
| Adjectives | Base + context | `"rosso (m. sing.)"` |
| Prepositions | No hint (`"___"`) | Tests knowledge |
| Articles | No hint (`"___"`) | Tests gender/number |

### Principle 3: Hint ≠ Answer
**Critical**: `question` must NEVER equal `text`.

### Principle 4: CEFR-Appropriate Complexity
- **A1-A2**: Simple SVO, present/past, basic pronouns
- **B1-B2**: Subjunctive, conditionals, passive, complex pronouns
- **C1-C2**: Nuanced subjunctive, indirect speech, register, literary forms

### Principle 5: Category Distribution
| CEFR Level | Min Examples per l3 |
|------------|---------------------|
| A1-A2 | 4-6 examples |
| B1-B2 | 3-4 examples |
| C1-C2 | 2-3 examples |

### Principle 6: Sentence Variation
Avoid repetitive structures within same category.

### Principle 7: Role Accuracy
Roles must reflect **syntactic function**.

✅ `{"text": "mangi", "role": "Verbo (2ª pers. sing. presente)"}`  
❌ `{"text": "mangi", "role": "Verbo"}` (too vague)

---

## Validation Checklist

Before adding sentences, verify:
- [ ] **Stand-alone viability**: Would a native speaker say this?
- [ ] **Hint sufficiency**: Can learner determine answer from hint?
- [ ] **Hint ≠ Answer**: Is hint different from correct text?
- [ ] **CEFR alignment**: Is complexity appropriate for level?
- [ ] **Role accuracy**: Does role reflect syntactic function?
- [ ] **Category coverage**: Are there enough examples?
- [ ] **Sentence variation**: Is structure different from others?
- [ ] **Explanation clarity**: Does explanation teach the rule?

## Automated Validation Script

Create `validate-language-pack.js`:
```javascript
const fs = require('fs');

function validateLevel(data, level) {
  let errors = [];
  
  data.forEach((q, i) => {
    // Check hint ≠ answer
    q.replies.forEach(r => {
      const block = q.sentence[r.questionIndex];
      if (block.question === block.text) {
        errors.push(`Q${i}: hint equals answer: "${block.question}"`);
      }
    });
    
    // Check sentence has ≥3 words (usually)
    if (q.sentence.length < 3 && level === 'A1') {
      const sentence = q.sentence.map(s => s.text).join(' ');
      errors.push(`Q${i}: too short for A1: "${sentence}"`);
    }
    
    // Check category exists
    if (!q.category.l1 || !q.category.l2 || !q.category.l3) {
      errors.push(`Q${i}: missing category`);
    }
  });
  
  return errors;
}

['a1', 'a2', 'b1', 'b2', 'c1', 'c2'].forEach(lvl => {
  const data = JSON.parse(fs.readFileSync(`languages/it/${lvl}.json`, 'utf8'));
  const errors = validateLevel(data, lvl);
  if (errors.length > 0) {
    console.log(`\n=== ${lvl.toUpperCase()} ERRORS ===`);
    errors.forEach(e => console.log(`  - ${e}`));
  }
});
```
